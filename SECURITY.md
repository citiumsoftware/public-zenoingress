# Security Policy

Citium Software takes the security of zenoingress seriously. This document explains how to report
vulnerabilities.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull
requests.**

Report privately using one of:

- **GitHub private advisory** (preferred): open a report under the repository's
  **Security → Advisories → Report a vulnerability** tab.
- **Email**: support@citiumsoftware.com

Please include:

- a description of the issue and its impact,
- the affected component(s) and version(s) — controller, proxy, edge, or chart,
- steps to reproduce or a proof of concept, and
- any suggested remediation.

## What to expect

We investigate every report and respond as quickly as we can. We'll keep you informed as we work on
a fix and, with your permission, are happy to credit you once it's released. We ask that you give us
a reasonable period to remediate before any public disclosure (coordinated disclosure).

Guaranteed acknowledgement and remediation times are available to customers under a commercial
support agreement — contact support@citiumsoftware.com.

## Supported versions

We provide security fixes for the **latest published release** of zenoingress. Please stay current
with the latest release to receive security updates.

## Scope

This policy covers the zenoingress container images and Helm chart published by Citium Software.
Vulnerabilities in third-party dependencies should also be reported to their respective maintainers.
