# Contributing

Thanks for your interest in zenoingress.

zenoingress is **proprietary software** developed and maintained by Citium
Software (see [LICENSE](./LICENSE)). Its source code is not public, and this
repository holds documentation, getting-started guides, and example scenarios
only.

## We do not accept external code contributions

Because zenoingress is proprietary, we **cannot accept pull requests that add or
modify product code**, and the source is not available here to change. Please do
not open code PRs against this repository — they will be closed. This keeps the
codebase's intellectual-property ownership clean and unambiguous.

## How you can help

You are very welcome to:

- **Report a bug** — open a [GitHub issue](https://github.com/citiumsoftware/public-zenoingress/issues)
  with the affected component and version (controller / proxy / edge / chart),
  what you expected, what happened, and steps to reproduce.
- **Request a feature** — open an issue describing the problem you're trying to
  solve and your use case.
- **Improve the docs** — small fixes to the documentation and example scenarios
  in this repository (typos, clarifications, broken commands) are welcome as
  pull requests. By opening such a PR, you agree your changes may be
  incorporated under the repository's terms.
- **Ask a question** — email us at <support@citiumsoftware.com>.

## Reporting security issues

**Do not report security vulnerabilities in public issues or pull requests.**
Follow the private disclosure process in [SECURITY.md](./SECURITY.md).
